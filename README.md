## Descripción

Sitio web de la clínica veterinaria "La Mary", desarrollado con HTML, CSS, JavaScript y Bootstrap 5, con Vite como servidor de desarrollo.

Páginas del sitio:

- Inicio (portada con catálogo de profesionales)
- Institucional
- Contacto
- Mascotas (administración)
- Veterinarios (administración)

## Funcionalidades de la 3ra etapa

Las páginas de Mascotas y Veterinarios permiten registrar, listar, editar y eliminar (con confirmación) cada registro. Los datos se guardan en el LocalStorage del navegador, cada entidad bajo su propia clave (`mascotas` y `veterinarios`), y el identificador se genera automáticamente al registrar.
